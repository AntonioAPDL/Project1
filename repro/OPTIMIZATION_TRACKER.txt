Scope
- Target: modularized R pipeline under R/environmetrics/ and runner scripts.
- Goal: improve performance and maintainability without changing outputs/behavior.
- Canonical behavior: outputs must match the current reference outputs.

Global Rules (non-negotiable)
1) No semantic changes: exact outputs must remain identical.
2) One optimization chunk per commit; validate after each chunk.
3) Do not change algorithmic logic unless explicitly approved.
4) Preserve randomness behavior: set.seed stays in one place; no extra RNG calls.
5) Avoid reordering computations that change floating-point accumulation unless proven safe.
6) No new dependencies unless justified and approved.

Optimization Principles
- Prefer vectorization and matrix operations when output is identical.
- Prefer apply/lapply/map over manual loops when identical and readable.
- Pre-allocate all large objects (no growing inside loops).
- Cache repeated computations; avoid recomputation inside loops.
- Avoid repeated I/O; read once and reuse.
- Use Rcpp only for heavy post-processing bottlenecks that are proven hotspots.
- If Rcpp is used:
  - Keep interfaces minimal and deterministic.
  - Provide unit-level validation vs R implementation.
  - Keep the R version as reference fallback.
