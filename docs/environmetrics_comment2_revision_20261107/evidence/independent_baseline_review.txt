Published mathematics and source verification

The left-truncated-normal CRPS formula in c2_tn_crps is algebraically equivalent
to the expression in Thorarinsdottir and Gneiting (2010): with Z=Phi(mu/sigma),
the published z*(2*Phi(z)+Z-2)/Z term equals z*(1-2*survival(z)/Z).
The density and final Phi(sqrt(2)*mu/sigma)/Z^2 terms agree. Quantiles use the
equivalent survival-probability inverse to avoid subtracting nearly equal CDFs.
The location/variance regression is an EMOS family adapted to log1p discharge;
the application window, bounds and training choices are explicitly documented.

source('scripts/build_comment2_external_baselines.R')
path <- '/tmp/comment2_external_baselines_20261107_r2'
s <- read.csv(file.path(path,'per_time.csv'))
worst <- 0
for(o in c('20210123','20211112','20211221','20220511','20221225')) {
  prediction <- readRDS(file.path(path,'predictions',paste0(o,'.rds')))
  y <- read.csv(file.path(path,'inputs/usgs_verification.csv'))
  observed <- y$Y[match(prediction$dates,y$date)]
  for(model in names(prediction$predictions)) {
    q <- prediction$predictions[[model]]
    error <- matrix(observed,nrow=nrow(q),ncol=ncol(q),byrow=TRUE)-q
    probabilities <- matrix(prediction$probabilities,nrow=nrow(q),ncol=ncol(q))
    direct <- 2*colMeans((probabilities-(error<0))*error)
    got <- s$crps[s$model==model & gsub('-','',s$cutoff_date)==o]
    worst <- max(worst,max(abs(got-direct)))
  }
}
cat('independent grid-score maximum discrepancy',worst,'\n')

Hardening observation communicated to the baseline owner

The initial log-tail algebra can suffer residual cancellation at extremely
negative standardized locations within artificial trial bounds:
c2_tn_crps(y=0,mu=-20,sigma=exp(-9)) returned -9.197433e-05;
y=1e-6 returned -1.304765e-04. These are not valid CRPS values. None of the
accepted training or forecast parameters is in that region: all accepted a
coefficients and all accepted standardized locations are positive, and the full
accepted-training formula comparison above is accurate to roundoff. The baseline
owner was asked to reject materially negative objective values and add a
regression, without silently changing accepted results. This is a robustness
issue outside the observed accepted-fit domain, not an accepted-result blocker.
