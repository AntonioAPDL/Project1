Why the preceding plan needs these refinements

A provenance PASS and a terminal 'VB converged' message cannot establish numerical
convergence. One saved May-2022/noTF median fit explicitly fails its terminal
convergence flags at the iteration budget despite that message. Other weak
Gaussian fits report convergence. Diagnosis must be case-specific.
2. T0 suppresses forecast transfer; noTF removes covariates/transfer from the reduced
model. Structural removal also affects corresponding discrepancy blocks. An
explicit comparison-role map prevents overinterpreting these distinct contrasts.
3. The local GloFAS archive has 1176 daily issuances with 28 leads and 51 members,
matching the selected article forecasts. A version-compatible 365-day paired
training design has 143--364 observations per lead. This supports a small published
EMOS comparator without downloading a new archive. A complete NWS training archive
has not been verified, so NWS calibration is not a dependency.
4. Deterministic 2000-point quantile representations support exact replay and match
the nominal selected synthesis size. Reporting uses the unchanged quantile CRPS
implementation; analytic truncated-normal CRPS is a clearly separate training
objective/accuracy check. Existing scores are imported without recomputation.
5. Compact curated features and USGS history allow external-baseline replay without
absolute server paths. New score artifacts and tables stay separate from the
existing publication-authority machinery.
6. Additional main-model fits would address diagnostic ambiguity only if necessary
for a specific scientific conclusion. The planned deliverable can instead report
that ambiguity and narrow the conclusion. No unconditional rerun is justified.
