Use one common observation/date/model registry for the following outputs:

Quantile reliability: for each origin, model, horizon, and probability, record
the valid denominator, counts below/below-or-equal, tie count, empirical rates,

Predictive intervals: recover .025/.975 quantiles from the full saved matrices.
The published figure/export convention uses R quantile type 8; it reproduces the
selected exported quantiles to 4.9e-15. Type 7 can differ and must not be substituted

Scoring: preserve the current estimator as a named legacy calculation, then
derive the exact empirical-distribution score and applicable random-sample
sensitivity from the original saved values. For m values x_i, define
A = mean_i |x_i-y| and D = sum_(i<j) |x_i-x_j|. Exact ECDF CRPS is A-D/m^2;
the iid-Ferro estimator is A-D/[m(m-1)] for m>1. The implemented s/(m+1)
quantile-grid score differs from ECDF CRPS by D/[m^2(m+1)]. Thus its correction
must be derived from the values, not applied to the old scalar scores blindly.
This algebra was independently checked on finite examples, including ties.

The AL/exAL synthesis actually uses random Uniform inverse-CDF draws conditional
on its constructed curve; subsequent sorting does not change CRPS. Existing
external references use deterministic quantile grids. Handle them accordingly.
Treat physical-member dependence and Gaussian-generation provenance explicitly
when labeling the Ferro sensitivity. Do not call an adjustment a universal
solution to member dependence. Exact ECDF scores remain available for every
retained finite representation. If analytic EMOS or full empirical climatology
scores are additionally used, identify their distribution representation.

  current observed discrepancy is below 5e-16.

  selection; CRPSS uses matched methods/denominators.

- C5 precision interpretation passes source-index/provenance checks; optional

- No optimization trace is called a chain, and no predictive-coverage result is
  offered as evidence of exact parameter-posterior accuracy.
- Run existing bounded C1/C2 and publication-preservation checks after changes;
  add meaningful tests for new scoring, date/scale alignment, feature labeling,

5. What remains for later computation

Keep a separate experiment register with no launch during this phase:
- Re-estimation/retuning under a changed dynamic or calibration specification.
- Independently optimized reduced-model comparisons if stronger component claims
  are desired beyond the already qualified sensitivities.
- Member-dependence, likelihood-weighting, and lead-dependent observation-model
  alternatives. Changes must reach all corresponding state, augmentation,
  scale/skewness, and objective updates, with a small correctness pilot first.
- A genuine same-target VB/MCMC comparison. Specify one representative origin
  and median quantile, matching sources, member multiplicities, priors, evolution
  policy, unknown quantities, and inputs. Establish the target and validate the
  sampler before timing a research run. A shorter-history study requires both
  methods on that same shorter target and cannot validate the full-history fit.
  Use multiple dispersed chains, rank-based Rhat, bulk/tail ESS, and Monte Carlo
  precision for reported intervals; no guaranteed short runtime is asserted.
- New fitted tail levels/families, additional verification origins, or a
  recalibration/refit response to observed diagnostic shortcomings, if needed.
- Rebuilding optional coefficient-window uncertainty only if its covariance/draw
  source can be recovered; otherwise it stays omitted. This is an artifact gate,
  not an automatic reason for refitting the full study.

Before that later campaign, refresh the evidence inventory and decide which
