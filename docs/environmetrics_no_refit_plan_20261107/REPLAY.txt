Reproduce the read-only existing-score audit from the workflow repository

Choose a new output directory under /tmp. This command does not fit models,
regenerate predictions or calculate proposed new verification results.

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
Rscript --vanilla docs/environmetrics_no_refit_plan_20261107/replay_existing_scores.R \
  --project-root /data/muscat_data/jaguir26/project1_ucsc_phd \
  --output-dir /tmp/NEW_no_refit_score_audit

Requires installed R packages jsonlite and digest and the current companion
runtime caches referenced by the publication manifest. It evaluates only the
two existing pure scorer definitions, then reads the small retained matrices.
It records file hashes, identities, shapes, original per-time score replay,
selected figure-quantile parity, algebra checks and R session information.
It refuses an existing output directory or one outside /tmp.

Expected audit scope:45 forecasts,1260 daily benchmark scores, score error below
1e-12 (observed4.44e-16). This is a parity audit, not the implementation of the
proposed scoring/calibration pipeline.
