Targeted C4/C6 decisions for the existing no-refit plan
Read-only refinement, 2026-11-08. No production tools, refits, new diagnostics,
source changes, or repetition of the completed 45-cache replay.

The plan is methodologically sound. The genuine remaining gaps are executable
decisions: Gaussian adjustment applicability, which baseline representation is
canonical, concrete case/output keys, missingness and tie rules, and tolerances.
These refinements belong in N04-N08 acceptance contracts, not another campaign.

1. Decide the score estimand before implementing N07

Use TWO separately identified views, preserving the old score unchanged:

PRIMARY NEW VIEW: exact CRPS of each saved finite predictive representation,
called ecdf_crps_saved_representation. This applies to every method. For the
external deterministic inverse-CDF grids, their equal-weight finite distribution
is explicitly the representation being evaluated. It is not claimed to be the
analytic EMOS distribution or full seasonal empirical CDF. This is a complete,
coherent comparison without refitting or RNG generation.

SENSITIVITY VIEW: Ferro's iid-based pairwise estimator where random-sample
semantics are relevant, with applicability/assumption flags. Do not call all
entries universally fair, infer independence of physical members, or manufacture
a correction for deterministic grid points. Retain both estimators side by side.

CRPSS decision:
Make exact-ECDF CRPSS the required new skill comparison for ALL methods, using
the same frozen CLIM-SEASONAL grid representation, date set and scale. Preserve
existing legacy CRPSS separately. The Ferro sensitivity need not have its own
CRPSS column to answer C4. This avoids a fictitious iid correction to deterministic
climatology solely to make estimator names match. If later adding an adjusted
skill score, use an explicitly known-distribution CRPS for the baseline and explain
the common distribution-level estimand; do not reuse its old grid-quadrature score.

Analytic EMOS and full seasonal empirical-distribution scores remain OPTIONAL,
separate representation IDs. Adding them is unnecessary for closure of C4/C6
and should not move the primary reference halfway through implementation.

3. Missing members and absent horizons

Current frozen data are complete. Default RELEASE POLICY should therefore be
fail closed: any unexpected nonfinite draw/member, missing observation, wrong
date, duplicate case or count different from the audited64/48/2000/51/7 is an
input-integrity failure, not permission to silently subset or impute.

Structural NWS unavailability beyond lead8 is not seven missing members at
leads9-28. It is not_applicable_horizon: no forecast-case rows there, and the
28day NWS table cell is absent/not applicable. Common eight-day comparisons
use exactly the same40 targets for every method. All28day rows use exactly140.

A generic scorer may support m=1 exactECDF=absolute_error, but iid adjustment
must return not_applicable_insufficient_values. That generic edge-case unit test
does not authorize accepting a corrupted current seven-member forecast with one
remaining value. Likewise preserve ties/duplicate members; never deduplicate.
If a future allowed partial-member policy is wanted, specify it in a new contract
with actual m and paired case sets; it is unnecessary for this release.

4. Decisive calibration and interval conventions

Quantile calibration primary outputs should use the existing HE4 final predictive
quantiles for the four principal competitors. This preserves the delivered values.
For other model forecasts, declare R type8 sample quantiles consistently as a NEW
diagnostic convention. Do not assert type8 generated every old univariate export
without checking: the completed proof established type8 parity for the selected
multivariate figure family, while the existing HE4 rows remain direct authority.

For deterministic references, preserve existing type1/generalized-inverse grid
quantiles from the comment2 summary or compute the same type1 values. For raw
ensembles, use an explicitly identified empirical inverse-CDF/type1 convention
for new distribution-calibration diagnostics. If a raw figure historically uses
another interpolation type, treat a figure-reconciliation row as a distinct
interval_definition instead of replacing the calibrated representation silently.
Persistence's quantiles all equal its point mass.

Required quantile event definitions:
  hit_strict=1[y<q_tau]; hit_weak=1[y<=q_tau]; exact_tie=1[y==q_tau].
Use exact comparisons on the frozen numeric values. Do not collapse nearby but
unequal numbers into ties with a generic numerical tolerance. An optional
near_tie diagnostic may be separate and must not change events or scores.
Counts satisfy n_weak=n_strict+n_tie. For discrete forecasts the population
quantile property is P(Y<q_tau)<=tau<=P(Y<=q_tau); do not claim both empirical
rates must equal tau, especially for persistence or tied empirical grids.
No random tie-breaking/RNG is necessary. Show both rates and counts.

For the requested displayed95% ribbon, compute R type8.025/.975 limits from
the exact source matrices, matching current figure generation. Event partition:
  lower_miss=1[y<lower]; inside=1[lower<=y<=upper]; upper_miss=1[y>upper].
This is a CLOSED central interval. Exact endpoint ties count inside; the three
counts partition n_valid. Width=upper-lower. For alpha=.05, proper interval score:
  width+(2/alpha)*(lower-y)*1[y<lower]+(2/alpha)*(y-upper)*1[y>upper].
Do not call the .05/.95 range a95% interval or a latent-state credible band a
held-out predictive interval. The small48/64 Monte Carlo sizes also affect tail
quantile precision; finite-count correction of CRPS does not remove that fact.

Original-scale convention should be explicit and minimal:
- Distribution scores: apply expm1 to EACH existing sample/grid value once.
- Preserve the displayed interval event by inverse-transforming its existing
  log-scale endpoints. Use interval_definition=inverse_of_log_type8_figure_band.
- For published targeted quantile losses, inverse-transform each authoritative
  existing log-scale q_tau; mark quantile_definition=inverse_of_source_quantile.
  This honors current fitted outputs. Recomputing type8 after nonlinear
  transformation is a separate optional diagnostic, not the same estimate.
- Means use mean(expm1(values)), never expm1(mean(values)).
No silently added truncation, winsorization or density-family substitution.

5. Acceptance tolerances and stopping rules

Exact checks: SHA256 identity, selected run/model/date keys, integer counts,
availability statuses, expected case sets, nominal probabilities, and boolean
event partitions. These have no numerical tolerance.

Legacy replay: retain existing per-case absolute tolerance1e-12 on log scale.
Selected type8 quantile-export parity: absolute tolerance1e-12 on log scale.
These are already far looser than observed floating-point differences.

New score identities and trusted-reference agreement:
  abs(a-b)<=1e-12+1e-12*max(abs(a),abs(b)) on log1p scale.
  abs(a-b)<=1e-10+1e-12*max(abs(a),abs(b)) on discharge scale.
Use independent pairwise toy formulas and sorted implementations, plus a trusted
library. Huge but finite current raw-scale values make a universal1e-12 ABSOLUTE
tolerance inappropriate. No tolerance can authorize nonfinite values or changed
forecasts. Test ties, point masses, two members,48/64/2000 counts, and scale changes.

Summary/CRPSS: recompute from unrounded per-case values and exact case-set joins,
with the same absolute-plus-relative tolerances. Require positive climatology
mean before dividing; otherwise status=undefined_zero_reference, not an infinity.
Ranks must come from the declared same estimator/scale/cases, never a selected
combination of the best cells from different methods.

Inverse-transform safety: all inputs finite; validate units and expm1 inputs;
fail on overflow/nonfinite outputs. Do not require log1p(expm1(z)) to agree at
1e-12 absolute for deeply negative z: subtraction near -1 can lose precision.
Compare against the prescribed transformation, and use unchanged log-scale
events for the figure-linked coverage reconciliation.

6. Reviewer4 closure criterion

The no-fit phase can complete the requested ANALYSIS: actual sample counts,
precise legacy estimator definition, exact-ECDF comparison, appropriately labeled
finite-sample adjustment sensitivity including the small Gaussian samples,
paired eight-day NWS results, and the factual discussion of why joint synthesis
need not dominate its strongest input. It must report any estimator-dependent
changes in ordering, even inconvenient ones.

Use closure wording such as 'requested score-method and sample-size sensitivity
completed under stated ensemble interpretations'. Do not say 'all scores now
fair' or 'ensemble dependence removed'. If a result changes substantially, the
article discussion should say so; that is an outcome of the requested audit,
not automatic authorization to alter the fits. Stronger dependence-model claims
remain outside what a scalar score correction establishes.
