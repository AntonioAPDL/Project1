R/environmetrics/02_helpers_core.R:852--912 calls the package synthesis entrypoint.
The inspected package source exdqlm/R/exdqlm_synthesize_from_draws.R:35--200
orders quantile anchors, shifts each fit's predictive draws, blends the adjusted
quantile FUNCTIONS between fitted probabilities, uses the extreme fits' functions
in the tails, rearranges the dense grid, and evaluates the result at Uniform draws.
The prior manuscript said anchor interpolation and deterministic r/(R+1) draws;

Limited implementation evidence: the currently inspected package source initializes

This source observation does not establish which code version produced archived

and this editorial revision does not certify complete numerical implementation.

Verified appendix transcription repairs

These manuscript-only repairs were explicitly reviewed with root. Given v=sigma*u,
the conditional Gaussian observation variance is B*sigma*v, hence the MCMC
observation covariance is Diag(B vector * sigma vector * v vector), rather than
the old dimensionally malformed product of vectors and a diagonal matrix.
The positive-truncated-normal underlying variance is the reciprocal of
1+C^2*gamma^2*sigma/(B*v); the old MCMC display omitted this reciprocal.
The second argument of N+ is now explicitly identified as this Gaussian variance.
The package's exdqlmISVB.R:192--200 confirms the reciprocal update.

For VB filtering, Gaussian information uses pi_tj=<1/(B_j*sigma_j*v_tj)> and
the offset b_tj=<offset/(B_j*sigma_j*v_tj)>/pi_tj. Observation covariance is
Diag(pi^-1). This preserves the joint scale/skewness moments instead of replacing
all products with separate means. The inspected exdqlmLDVB.R:653--655 uses
ex.q=(E.invb.inv.sigma*E.inv.uts)^(-1) and its equivalent weighted ex.f.
The main computation paragraph now describes groups of cyclic updates, avoiding
a claim that its paragraph order is the literal software execution order.
No estimation code, fits, samples, scores or selected identities were changed.
