Scope

Implemented in isolated workflow/article worktrees only. No research process,

Canonical figure policy

Figures/ is canonical, matching MANUSCRIPT_ASSET_MANIFEST.json and ArticleRepoLayout.
The historical sync_legacy_uppercase_figures.py filename is retained for callers,
but now copies from canonical Figures/ to optional figures/ compatibility copies.
It never removes a directory or unmanaged asset. --relative-path may be repeated
for a bounded refresh; full-tree refresh first requires all five current families.
Sources and destinations are validated before writes, including symlink/escape
checks for image and metadata targets. Manifests record source/target/hash/bytes.

An additional wiring defect was found and corrected: refresh_cutoff_synthesis_families
passed its uppercase canonical directory as the lowercase mirror target and then
cleared that target. Both call sites now use compatibility_figures_dir; the helper
rejects self-copy, unexpected destination roots and symlinks, and preserves
unmanaged files. No broad refresh was run. The figure agent subsequently added
separate bounded presentation hooks to this same script, preserving this repair.

README and generated README source now declare the same canonical direction.
Figures/README identifies the old uppercase mirror_manifest as historical.
The manuscript/source filenames, stable figure labels and asset selection remain.

Current article contract migration

A pure article-side manuscript_text_contract.py supplies active-LaTeX handling,
scientific concept checks, stable label/order checks, and bibliography URL
resolution. The workflow loads it via current_article_contract.py. Comments cannot
satisfy requirements; a URL in an uncited bibliography entry cannot satisfy a
software availability link. A cited entry resolves a URL without requiring the
same literal URL to clutter the manuscript prose.

Current article gates now protect the six-section order, data/model/evaluation
separation, illustration-before-interpretation, appendix matrix/augmentation,
scientific concepts and the actual numerical/manifest checks. They do not require
the previous rejected prose, internal runtime keys or obsolete section headings.
The runtime checks retain parallel seven-quantile fitting, approximate combined
two-hour timing, staged-input scope, 64 cores/503 GiB and hardware/implementation
context. Existing exclusions of unsupported timing decompositions remain.

The scope was extended from the initial two reviewer modules/runtime gate to the
remaining-item, forecast-design, latest-issue and two cross-repository validators,
because they duplicated the same current-article sentences. This is a necessary
wiring repair for the authorized rewrite. All historical response literal
requirements in the eight affected modules were compared as parsed Python values
against HEAD and are identical. Their actual response file remains unchanged.
No numeric/source/hash branch was weakened or removed.

The narrow selected-support metadata test now accepts the prior full-render v2
metadata plus the explicit component-only v3 revision, or a future complete v3
render. It checks the corrected label, derived daily period and calendar-year
conversion. The underlying component identity and numerical summaries retain
their original assertions.
