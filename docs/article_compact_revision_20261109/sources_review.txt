CONCLUSION

The numerical-table compression and four supporting forecast redraws can be made
from compact CSV files already in the article repository. They do not require
model objects, predictive-cache reads, new draws, new forecasts, or fitting. A
single existing CSV already holds the complete S1 matrix, which is safer than
joining values parsed from three TeX tables. The plan should explicitly retain
all methods and both horizons in S1/S5, preserve different score conventions, and
use the saved exact 95% endpoints rather than the seven-quantile CSV for redraws.
The one conditional item is a fully redrawn five-axis historical-input figure:
the article setup bundle visibly contains the existing raster figures and
metadata, rather than a compact numeric plot-input CSV. Its preferred first
attempt should combine the two existing readable displays with a shared caption;
retain two pages if this does not fit legibly. A numeric redraw would first need
a separately justified, narrow export of the existing plotting data, not a
broader regeneration command.

5. KEY, ROUNDING AND PRESENTATION RULES

Use original method IDs internally and a one-to-one display-label map:
  RAW-GLOFAS->GloFAS;RAW-NWS->NWS;CLIM-SEASONAL->Seasonal climatology;
  PERSISTENCE->Persistence;EMOS-GLOFAS->GloFAS EMOS.
Normalize dates from ISO/compact strings into actualdate objects at input, not
substring-matching labels. Cast horizon to integer, tau to an explicit allowed
numeric set. Reject duplicate keys, unexpected methods/origins/scales, missing
required cases or accidental extra rows before rendering.

Compute aggregates from full precision and round only the finaldisplay once.
Retain five decimals initially to avoid mixing presentation precision changes
with scientific/exhibit changes. Never compute skill from rounded CRPS cells or
mean the five origin-specific CRPSS values: pooled skill is1-pooledCRPS divided
by pooledclimatologyCRPS on the same cases. For pooled quantile losses, aggregate
140daily savedlosses at eachtau. Do not pool across probabilities or horizons.

S1 two horizon panels have13 and14rows, not14complete rows inboth. NWS28d should
be explicitly unavailable if a fixed14-rowlayout is preferred. Use a concise
shared model key limited to labels present in that table. Essential table-local
scale,denominator,horizon and score-method notes remain even when definitions
also appear inmain/SI. Shared notes should replace duplicatednotes, not remove
interpretability.
